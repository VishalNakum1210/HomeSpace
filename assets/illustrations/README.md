# HomeSpace artwork

`memory-garden.png` is a transparent header illustration recreated with the
image-generation tool from the approved HomeSpace concept in this conversation.
It contains the green house, orange roof, plants and framed photos.

It is decorative and excluded from screen-reader semantics. No text is baked
into it. It ships in the Flutter asset bundle and works offline in both themes.
Original PNG dimensions: 2135 × 736. File size: 924,328 bytes.

Small album and profile decorations are scalable native Flutter artwork in
`lib/design/cartoon_artwork.dart`. The original code-drawn application logo in
`lib/design/space_symbols.dart` remains unchanged.
